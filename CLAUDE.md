# Project Rules for Claude Code / AI Assistants

> **Dành cho mọi thành viên dùng Claude Code hoặc AI assistant khác trên repo này.**
> Vui lòng đảm bảo AI của bạn tuân thủ các quy tắc dưới đây trước khi commit/push.

---

## 🚫 TUYỆT ĐỐI KHÔNG

### 1. Không thêm trailer Co-Authored-By cho AI

**CẤM** các trailer sau trong commit message:

```
Co-Authored-By: Claude <noreply@anthropic.com>
Co-Authored-By: Claude Sonnet ... <noreply@anthropic.com>
Co-Authored-By: GPT-4 <...>
Co-Authored-By: Copilot <...>
```

Lý do: Trailer này làm AI hiện lên GitHub contributor list, gây lẫn với contributor thật.

### 2. Không nhắc Claude/AI/assistant trong commit message

**CẤM** các cụm từ trong title, body, footer của commit:

- "🤖 Generated with Claude Code"
- "Generated by AI"
- "Written by Claude"
- "AI-assisted commit"
- Bất kỳ reference nào tới `claude.ai`, `anthropic.com`, OpenAI, Copilot

### 3. Không đổi `user.name` / `user.email` sang tên AI

Author git **luôn** phải là tên người thật của bạn, ví dụ:
```bash
git config user.name "xuanduc"
git config user.email "xuanduc24905@gmail.com"
```

## ✅ ĐÚNG

Commit chỉ gồm tên bạn và nội dung công việc:

```
feat: them pipeline cross-domain eval tren VN Aerial

- Script download 635 anh tu Ultralytics Platform
- MD5 verify khong leak voi V5+
- Eval 9 model x 3 bo test
```

**KHÔNG** có dòng `Co-Authored-By: Claude...` ở cuối.

## 🔧 Nếu đã lỡ commit có trailer Claude

### Fix 1 commit chưa push

```bash
git commit --amend
# Xoá dòng "Co-Authored-By: Claude..." trong editor, save
git push --force-with-lease origin <branch>
```

### Fix nhiều commit đã push

```bash
# Rewrite tất cả commit, xoá trailer Claude
FILTER_BRANCH_SQUELCH_WARNING=1 git filter-branch --msg-filter \
  'sed "/^Co-Authored-By:.*[Cc]laude/d"' -- --all

# Dọn backup refs
git for-each-ref --format='%(refname)' refs/original/ | xargs -n1 git update-ref -d

# Force push
git push --force origin main
git push --force origin <other-branches>
```

### Nếu commit "lỗi" chỉ trên branch riêng của bạn

Xoá branch đó trên remote để commit orphan (GitHub tự GC sau 90 ngày):
```bash
git push origin --delete <tên-branch>
```

## 🛠️ Config Claude Code để không tự thêm trailer

Trong `~/.claude/settings.json` thêm:
```json
{
  "commit": {
    "coAuthor": false,
    "signOff": false
  }
}
```

Hoặc khi dùng `/commit` trong Claude Code, luôn kiểm tra output trước khi confirm, bỏ dòng `🤖 Generated` và `Co-Authored-By` nếu có.

## 📝 Quy ước khác của project

### Commit message
- Tiếng Việt không dấu (hoặc tiếng Anh) — để dễ đọc trên môi trường không hỗ trợ Unicode
- Prefix: `feat:`, `fix:`, `docs:`, `refactor:`, `tieuluan:`, `dataset:`, `pipelines:`, `eval:`, `audit:`
- Body mô tả bullet points cho các thay đổi lớn

### Branch
- `main` — branch chính, đã merge mọi feature xong
- `<tên>/<feature>` — branch cá nhân (ví dụ `xuanduc/thesis-v6`, `phamHung/clspw-ablation`)
- Tránh branch tên chung chung

### Pull request
- Luôn PR về `main`, không push trực tiếp main
- Mỗi PR có mô tả rõ: làm gì, test thế nào, có breaking changes không
